Đoạn Code Sau Khi Sửa Lỗi 

function showGreeting() {

    let hour = new Date().getHours();

    let greeting = document.getElementById("23010001_txt_msg");

    if (hour < 12) {

        greeting.innerText = "Chào buổi sáng!";

    } else if (hour < 18) {

        greeting.innerText = "Chào buổi chiều!";

    } else {

        greeting.innerText = "Chào buổi tối!";

    }

}

Giải Thích Các Lỗi Đã Sửa

  • getelementbyid sai cú pháp.
    Sửa thành: getElementById
  • innertext viết sai chữ hoa chữ thường.
    Sửa thành: innerText
  • Câu lệnh: else (hour < 18) bị sai cú pháp JavaScript.
    Phải sửa thành: else if (hour < 18)
  • Đoạn code cũ không có lời chào buổi tối.
    Đã bổ sung: else { greeting.innerText = "Chào buổi tối!"; }
